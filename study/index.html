Adding new content

NotebookLM podcast

  1. Download the Audio Overview into Nursing Website Content / NotebookLM Podcasts in Google Drive.
  2. On the PC, run the sync. The episode is imported and transcribed privately.
  3. Set approved to yes in episodes.csv (and transcript_public if you want the transcript on the site), then sync again with publishing on.

Notability note

  1. Copy the PDF from Notability Notes into Approved for Website. Nothing else in Notability Notes is ever read.
  2. Sync with publishing on. Removing the PDF from Approved for Website takes it off the site at the next sync.
Private Reference Materials and everything not approved stay off GitHub. This site is public, so approve only material without names, grades or patient details.
